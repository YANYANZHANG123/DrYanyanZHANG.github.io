# Yanyan Zhang — Academic Homepage

A clean, bilingual academic homepage for **Yanyan Zhang**, inspired by the concise academic-homepage style of Kun Chen's website.

## Structure

```text
yanyan-zhang-academic-homepage/
├── index.html
├── publications.html
├── assets/
│   └── style.css
└── README.md
```

## Deploy with GitHub Pages

1. Create a repository named:

```text
YOUR-GITHUB-USERNAME.github.io
```

2. Upload `index.html`, `publications.html`, and the `assets/` directory.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Open:

```text
https://YOUR-GITHUB-USERNAME.github.io/
```

## Personalize before publishing

Replace these placeholders:

- `[Your current institution / laboratory]`
- `[Your undergraduate institution]`
- `your.email@example.com`
- Google Scholar / GitHub / ORCID links
- Remaining publication titles, DOI, paper and code links
- `assets/profile.jpg` with your preferred academic portrait

The current publication list intentionally contains only information that has been explicitly identified in the working draft. Add the complete publication list from your CV or Google Scholar before publication.

## Design

The page includes:

- Responsive mobile layout
- Sticky navigation
- Bilingual section headings
- Research-interest tags
- Education / experience timeline
- Research-topic cards
- News timeline
- Selected publications
- Dedicated publications page
- Contact and academic links

The visual style is deliberately restrained: white background, thin borders, blue academic links, rounded tags, and no unnecessary animations.
